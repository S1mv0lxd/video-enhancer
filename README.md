# Video Enhancer 🎬

Расширение для браузера (Chrome / Edge / Firefox, Manifest V3) для любых видеоплееров:
растягивает видео на весь экран **без обрезки кадра**, добавляет плавность.
Работает на YouTube, VK Видео, Rutube, Twitch, Кинопоиске и любых других плеерах,
включая Shadow DOM и iframe-плееры.

## Возможности

- **Растягивание без приближения** — убирает чёрные полосы и заполняет экран, сохраняя весь кадр:
  - по ширине;
  - по высоте;
  - заполнить экран.
- **Плавность** — автоподстройка скорости воспроизведения под герцовку монитора (убирает рывки);
  режим «Резкий» добавляет чёткость.
- **Панель FPS и запаса GPU** — реальная герцовка экрана и время кадра в мс.
- **Любые плееры** — обычные `<video>`, открытые и закрытые Shadow DOM, iframe.
- **Полный экран** — панель видна в fullscreen, настройки не слетают при выходе.
- **Запоминание по сайтам** — настройки применяются автоматически при повторном заходе.
- **Компактная панель** — сворачивается, когда курсор не наведён, центрируется по видео.

## Установка

### Готовый ZIP (проще всего)
1. Скачайте `video-enhancer.zip` в разделе [Releases]([releases/latest](https://github.com/S1mv0lxd/video-enhancer/releases/latest)).
3. Распакуйте в постоянную папку (не удаляйте её).
4. Откройте `chrome://extensions` (Chrome / Edge).
5. Включите «Режим разработчика» (переключатель справа сверху).
6. «Загрузить распакованное расширение» → выберите распакованную папку.

### Из исходников
Скачайте код кнопкой «Code → Download ZIP» и выполните шаги 3–5 выше.

Firefox: `about:debugging#/runtime/this-firefox` → «Load Temporary Add-on…» → `manifest.json`.

## Использование

Над центром видео появляется компактная панель:
- **Масштаб** — режимы растягивания (Выкл / По ширине / По высоте / Заполнить экран);
- **Плавность** — Выкл / Простой / Резкий + панель FPS и запаса GPU, кнопка «Закрепить на видео»;
- **⚙ Настройки** — автоприменение, запоминание для сайта, автоскрытие, компактный режим.

## Как это работает

- Растягивание — `transform: scale(sx, sy)` + `object-fit: fill` на элементе `<video>`:
  независимое масштабирование по осям, кадр не обрезается.
- Плавность — замер fps контента (`requestVideoFrameCallback`) и герцовки экрана
  (`requestAnimationFrame`), затем микро-коррекция `playbackRate` для ровного кадра.
- Поиск плееров — MutationObserver + скрипт `probe.js` в MAIN-мире, который перехватывает
  `attachShadow` и находит видео даже в закрытых Shadow DOM.
- Весь UI изолирован в Shadow DOM и не конфликтует со стилями сайтов.

## Ограничения

- Плееры, рисующие видео через `<canvas>`/WebGL без элемента `<video>`, не поддерживаются.
- Если контейнер плеера имеет `overflow: hidden`, растягивание может обрезаться его границами.
